For the monitoring section (and several other components), this repository uses **Helm** to install common default dependencies.  
I assume you are already familiar with Helm and how it works. If not, please refer to the official documentation to understand the basics and its role in managing Kubernetes packages:

🔗 **https://helm.sh/docs/**

Helm is used throughout this repository to simplify deployments, ensure consistency, and manage updates across the various namespaces.
